# Telegram 2D Adventure

Готовий прототип 2D-гри для запуску у Telegram Mini App.

## Що є
- персонаж;
- біг і стрибок;
- монети;
- перешкоди/вороги;
- 3 життя;
- рівні;
- збереження кількості монет у браузері;
- сенсорні кнопки для телефона;
- підтримка Telegram WebApp.

## Запуск локально
Потрібен простий HTTP-сервер, наприклад:
`python3 -m http.server 8080`
Потім відкрити `http://localhost:8080`.

## Підключення до Telegram
1. Створити бота через BotFather.
2. Опублікувати цю папку на HTTPS-хостингу.
3. У BotFather налаштувати Web App/Menu Button і вказати HTTPS-адресу `index.html`.
4. Відкрити бота та натиснути кнопку гри.

Для реального рейтингу між користувачами потрібен backend/база даних; поточний прототип зберігає монети локально.
